# Шаблон сайта

Структура:

    site/
    ├── index.html      — разметка страницы
    ├── css/style.css   — стили (цвета и шрифт в самом начале, блок :root)
    ├── js/script.js    — переключатель темы
    └── img/            — сюда кладите картинки

Как открыть: двойным кликом по index.html или через локальный сервер:

    python3 -m http.server 8000

и затем http://localhost:8000 в браузере.

Что менять в первую очередь:
1. <title> и название «МойСайт» в index.html
2. Тексты в секциях (комментарии в HTML подсказывают, где что)
3. Цвета в css/style.css (переменные --bg, --accent и др.)
4. Заменить блок .pic на <img src="img/photo.jpg" alt="...">
